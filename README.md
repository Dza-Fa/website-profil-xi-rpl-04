# website-profil-xi-rpl-04

REFLEKSI INDIVIDU

1. Sendiri vs Git & GitHub:Sendiri rentan kode tertimpa/hilang dan riwayat manual; Git/GitHub mencatat riwayat perubahan otomatis, aman di cloud, dan mendukung kolaborasi tim.
2. Manfaat Branch:Mengisolasi fitur baru/eksperimen agar tidak merusak kode utama yang stabil.
3. Mengapa PR Diperlukan: Sebagai pintu gerbang pemeriksaan kode sebelum digabungkan ke cabang utama.
4. Manfaat Code Review: Menjaga kualitas kode, menemukan bug lebih cepat, dan meratakan pengetahuan dalam tim.
5. Error Tersulit:Merge Conflict (saat dua orang mengubah baris kode yang sama di berkas yang sama).
6. Solusi Error: Berdiskusi dengan rekan tim untuk memilih kode yang benar, lalu menggunakan (Merge Editor) di editor kode.
7. Kontribusi Terbesar: Merapikan struktur repository, memandu (branching),dan membantu menyelesaikan konflik kode.
8. Kebiasaan Profesional: Selalu bikin branch baru, rajin commit dengan pesan jelas, dan wajib Code Review sebelum merge.
