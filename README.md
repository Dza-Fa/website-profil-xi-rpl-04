# # website-profil-xi-rpl-04

## REFLEKSI INDIVIDU

### 1. Apa perbedaan bekerja sendiri dengan bekerja menggunakan Git dan GitHub?

Bekerja sendiri lebih bebas karena semua pekerjaan dilakukan sendiri, sedangkan menggunakan Git dan GitHub memungkinkan kita bekerja sama dengan anggota kelompok, membagi tugas, dan menggabungkan hasil pekerjaan dengan lebih teratur.

### 2. Apa manfaat branch?

Branch berguna agar setiap anggota dapat mengerjakan tugasnya masing-masing tanpa mengganggu pekerjaan anggota lain atau branch utama.

### 3. Mengapa Pull Request diperlukan?

Pull Request diperlukan agar perubahan yang sudah dibuat dapat diperiksa terlebih dahulu sebelum digabungkan ke branch main.

### 4. Apa manfaat Code Review?

Code Review membantu menemukan kesalahan pada kode, memastikan pekerjaan sudah sesuai tugas, dan membuat kode menjadi lebih rapi.

### 5. Error apa yang paling sulit kalian selesaikan?

Error yang cukup sulit adalah ketika mengatur branch dan memastikan hasil pekerjaan dapat tersimpan dan terkirim ke repository GitHub dengan benar.

### 6. Bagaimana kalian menemukan solusinya?

Saya membaca pesan error, mengecek kembali perintah Git yang digunakan, berdiskusi dengan anggota kelompok, dan mencari solusi ketika masih mengalami kesulitan.

### 7. Apa kontribusi terbesar kalian dalam kelompok?

Kontribusi terbesar saya adalah membuat dan menyelesaikan halaman `anggota.html` yang berisi informasi anggota tim sesuai pembagian tugas.

### 8. Jika menjadi programmer profesional, kebiasaan apa dari kegiatan ini yang akan kalian pertahankan?

Saya akan mempertahankan kebiasaan menggunakan branch, membuat commit dengan pesan yang jelas, mengecek pekerjaan sebelum melakukan push, dan berkomunikasi dengan anggota tim.

## REFLEKSI AKHIR

**Sebelum belajar GitHub, saya berpikir bahwa...**  
GitHub hanya digunakan untuk menyimpan kode atau project secara online.

**Setelah melakukan kolaborasi dengan GitHub, saya memahami bahwa...**  
GitHub dapat digunakan untuk bekerja sama dalam tim, membagi pekerjaan melalui branch, melakukan Pull Request, Code Review, dan menggabungkan pekerjaan ke branch utama.

**Kesalahan/error yang saya alami mengajarkan saya bahwa...**  
Error bukan berarti pekerjaan gagal, tetapi dapat membantu kita mengetahui bagian yang salah dan belajar mencari solusi dengan lebih teliti.

**Jika saya bekerja sebagai programmer dalam sebuah tim, saya akan...**  
Membagi tugas dengan jelas, menggunakan branch masing-masing, berkomunikasi dengan anggota tim, dan melakukan Code Review
